[![Python 3.10](https://img.shields.io/badge/python-3.10-blue.svg)](https://www.python.org/downloads/)

Code for calculating frontal ablation (calving + subaqueous melt) using the **multiple-fluxgate method**.  
Case study: Manso Glacier, Monte Tronador (Northern Patagonia).

---

## Description

This repository contains two independent routines:

| Routine             | Temporal resolution | Period    | Output   |
|--------------------|-------------------|-----------|----------|
| `FA_annual.py`      | Annual            | 2013–2023 | Mm³/year |
| `FA_subseasonal.py` | 40–90 day intervals | 2017–2024 | m³/day   |

Each routine follows a three-step workflow:

1. **Flowline-level calculations**  
2. **Fluxgate-level aggregation**  
3. **Glacier-wide totals**

## Installation

```bash
git clone https://github.com/lautaroclavero/Frontal_Ablation_Multiple_Fluxgate.git
cd Frontal_Ablation_Multiple_Fluxgate
conda env create -f environment.yml
conda activate manso_fa

Use Anaconda or Miniconda.
Installation via pip only is not recommended due to geospatial dependencies.

Tested environment
OS: Windows 10 (Anaconda Prompt)
Python: 3.10
geopandas: 0.14
rasterio: 1.3
gdal: 3.6
Usage
Annual calculation
python FA_annual.py
Subseasonal calculation
python FA_subseasonal.py
Generate figures
python FA_annual_visualization.py
python FA_subseasonal_visualization.py

Outputs are automatically saved in the output/ directory.

Data

All input data are included in Input_Data_Manso/.

Raster data (GeoTIFF)
Glacier masks: define calving front position
Surface velocity fields:
vels_raw/: raw velocity grids (GIV)
vels_final/: processed velocity fields

Processing includes:

directional filtering using terrain aspect
removal of inconsistent flow (>60°)
spline interpolation
spatial smoothing (3×3 filter)
Ice thickness: reference raster (2012)
Vector data (Shapefile)
Flowlines: MultiPoint geometries (3 m spacing)
Attributes: LINE_ID, ID, DIST, X, Y
Stable bedrock polygons: used for NMAD uncertainty estimation
File naming conventions
Annual
Velocities: YYYY.tif
Processed: YYYY_final.tif
Masks: YYYY_mask.tif
Subseasonal
Masks: YYYYMMDD_mask.tif
Velocities: YYYYMM.tif
Processed: YYYYMM_final.tif
Output
Routine	Output files
Annual	annual_flowlines_results.csv, annual_fluxgates_results.csv, annual_frontal_ablation.csv
Subseasonal	flowlines_results.csv, fluxgates_results.csv, frontal_ablation_results.csv
Troubleshooting
PROJ errors

If you see:

ERROR 1: PROJ: proj_identify: Cannot find proj.db

Run:

set PROJ_LIB=%CONDA_PREFIX%\Library\share\proj

Or in Python:

import os
os.environ["PROJ_LIB"] = os.path.join(os.environ["CONDA_PREFIX"], "Library", "share", "proj")
Test installation
python -c "import rasterio; print('Rasterio OK')"
