# Frontal ablation trends of Manso Glacier, Northern Patagonia

[![Python 3.10](https://img.shields.io/badge/python-3.10-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Conda](https://img.shields.io/badge/conda-environment-green.svg)](https://docs.conda.io/)
[![Paper](https://img.shields.io/badge/paper-in%20press-red.svg)](#citation)

Code for calculating frontal ablation (calving + subaqueous melt) using the **multiple-fluxgate method**. Case study: Manso Glacier, Monte Tronador (Northern Patagonia).

---

## Description

This repository contains two independent routines:

| Routine             | Temporal resolution | Period    | Output   |
| ------------------- | ------------------- | --------- | -------- |
| `FA_annual.py`      | Annual              | 2013–2023 | Mm³/year |
| `FA_subseasonal.py` | 40–90 day intervals | 2017–2024 | m³/day   |

Each routine follows a three-step workflow:

1. **Flowline-level calculations** (velocity at glacier terminus, ice front displacement rate, frontal ablation rate, thickness)
2. **Fluxgate-level aggregation** (between adjacent flowlines)
3. **Glacier-wide totals**

## Data

All input data are included in `Input_Data_Manso/`.

### Raster data (GeoTIFF)

* **Glacier masks:** binary rasters derived from glacier outlines (glacier = 1, non-glacier = 0), used to delineate the calving front position.

* **Surface velocity fields (used to compute ice fluxes across flux gates):**

  * `vels_raw/`: velocity magnitude grids (m yr⁻¹/m d⁻¹) obtained directly from feature tracking using Glacier Image Velocimetry (GIV) (Van Wyk de Vries & Wickert, 2021).
  * `vels_final/`: post-processed velocity fields used in the analysis.

  Post-processing includes:

  * resampling and directional filtering using terrain aspect
  * removal of pixels with flow direction deviating >60° from aspect
  * gap filling using spline interpolation
  * spatial smoothing (3×3 low-pass filter)

* **Reference ice thickness:** GeoTIFF raster for 2012 (Zorzut et al., 2020), used to compute ice fluxes.

---

### Vector data (ESRI Shapefile)

* **Flowlines:** MultiPoint geometries with regularly spaced points (3 m spacing). Attribute table includes:

  * `LINE_ID`: flowline identifier
  * `ID`: point index
  * `DIST`: distance from the up-glacier origin (m)
  * `X`, `Y`: UTM coordinates (zone 19S)

  These are used to define flux gates and extract velocity profiles.

* **Stable bedrock polygons:** manually delineated areas located outside the glacier over stable terrain. These are used to estimate velocity uncertainty using the Normalized Median Absolute Deviation (NMAD) to quantify velocity errors over stable terrain.

---

### File naming conventions

To ensure compatibility with the scripts, input files must follow these naming conventions:

* **Annual data**

  * Raw velocities: `YYYY.tif`
  * Processed velocities: `YYYY_final.tif`
  * Glacier masks: `YYYY_mask.tif`

* **Subseasonal data**

  * Masks: `YYYYMMDD_mask.tif`
  * Raw velocities: `YYYYMM.tif`
  * Processed velocities: `YYYYMM_final.tif`

---

To apply this code to another glacier, replace the contents of `Input_Data_Manso/` with your own data while preserving the structure and naming conventions.
