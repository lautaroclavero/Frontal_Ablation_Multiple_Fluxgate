# Frontal ablation trends of Manso Glacier, Northern Patagonia[![Python 3.10](https://img.shields.io/badge/python-3.10-blue.svg)](https://www.python.org/downloads/)[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)[![Conda](https://img.shields.io/badge/conda-environment-green.svg)](https://docs.conda.io/)[![Paper](https://img.shields.io/badge/paper-in%20press-red.svg)]()Code for calculating frontal ablation (calving + subaqueous melt) using the **multiple-fluxgate method**.  Case study: Manso Glacier, Monte Tronador (Northern Patagonia).---## DescriptionThis repository contains two independent routines:| Routine             | Temporal resolution | Period    | Output   || ------------------- | ------------------- | --------- | -------- || `FA_annual.py`      | Annual              | 2013–2023 | Mm³/year || `FA_subseasonal.py` | 40–90 day intervals | 2017–2024 | m³/day   |Each routine follows a three-step workflow:1. **Flowline-level calculations** (velocity at glacier terminus, ice front displacement rate, frontal ablation rate, thickness)2. **Fluxgate-level aggregation** (between adjacent flowlines)3. **Glacier-wide totals**---## Repository structure

Data
All input data are included in Input_Data_Manso/.
Raster data (GeoTIFF)


Glacier masks: binary rasters used to define calving front position.


Surface velocity fields:


vels_raw/: raw velocity grids from Glacier Image Velocimetry (GIV)


vels_final/: processed velocity fields




Processing steps include:


directional filtering using terrain aspect


removal of inconsistent flow directions (>60°)


spline interpolation


spatial smoothing (3×3 filter)


Ice thickness: reference raster (2012) used for flux calculations.



Vector data (ESRI Shapefile)


Flowlines: MultiPoint geometries (3 m spacing) with attributes:


LINE_ID, ID, DIST, X, Y




Stable bedrock polygons: used to estimate velocity uncertainty (NMAD).



File naming conventions
Annual data


Velocities: YYYY.tif


Processed: YYYY_final.tif


Masks: YYYY_mask.tif


Subseasonal data


Masks: YYYYMMDD_mask.tif


Velocities: YYYYMM.tif


Processed: YYYYMM_final.tif


To adapt this code to another glacier, replace Input_Data_Manso/ while preserving structure and naming.

Troubleshooting
PROJ errors (proj.db not found)
If you see errors like:
ERROR 1: PROJ: proj_identify: Cannot find proj.db
Run:
set PROJ_LIB=%CONDA_PREFIX%\Library\share\proj
Or in Python:
import osos.environ["PROJ_LIB"] = os.path.join(os.environ["CONDA_PREFIX"], "Library", "share", "proj")

Verify installation
python -c "import rasterio; print('Rasterio OK')"
